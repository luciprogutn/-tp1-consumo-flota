## Programas incluidos
* `Viaje.java`: Programa para registrar un viaje de un camión y calcular el consumo de combustible, rendimiento (km/l) y costo del viaje.
* `Flota.java`: Programa para procesar una flota de seis camiones, informando el consumo global y clasificando cada camión según su eficiencia.

## Compilación y ejecución
Instrucciones para compilar y ejecutar los programas desde la consola:

# Para compilar y ejecutar Viaje:
javac Viaje.java
java Viaje

# Para compilar y ejecutar Flota:
javac Flota.java
java Flota
